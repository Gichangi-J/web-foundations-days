About QuickNotes

QuickNotes is a simple note-taking app created as part of the Learning with Plp website. It helps you capture and organize your thoughts.

How to use QuickNotes

  1. Go to the home page
  2. Click on the "Add note" button
  3. Type your note in the input field
  4. Click on the "Add Note" button to save your note

Features

  • Note taking
  • Note listing
  • Note deletion

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Add note
Ctrl + S Save note
Ctrl + D Delete note
